# Security reporting

This local MVP has not been audited or publicly deployed. No bug bounty or guaranteed response time is offered.

For a vulnerability, use GitHub private vulnerability reporting if enabled on this repository. If unavailable, contact the repository owner privately through an existing verified channel before disclosing exploitation detail. No security email or team identity has been supplied; none is invented here. Public issues may describe non-sensitive build/documentation problems only.

Include affected revision, minimal reproduction, expected/actual behavior, asset or permission impact and suggested mitigation where known. Never include keys, credentials or funded exploitation transactions. Review docs/security.md for the current trust model, admin powers and limitations. Production release requires independent review and validated real oracle/collateral/liveness integrations.
